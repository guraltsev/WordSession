What Word Session does

Word Session remembers which Microsoft Word documents you have open, and where your cursor is in each of them, so that you can reopen all of them later with one click or one command. A saved set of documents is called a session.

  • It saves sessions when you ask, and also automatically in the background (autosave).
  • Restoring a session reopens the documents and puts the cursor back where it was. It never closes or changes anything that is already open.
  • It runs in your own Windows account. It needs no administrator rights, no internet connection and no Python.
  • Everything is controlled from an icon in the notification area (the tray), from a page in your web browser (the manager), or from the command line.

Word Session does not save the contents of your documents. A session holds only the file names, the cursor positions and which document was in front. Save your work in Word as usual.

Quick start

  1. Unzip Word Session and run word-session.exe (see Set up). An icon appears in the notification area and the manager opens in your browser. Press Create Start menu shortcut on the Settings page so you can start it from the Start menu next time.
  2. Open the documents you are working on in Word.
  3. Press Save current session on the Sessions page, or choose Save session now in the tray menu.
  4. Later, even after a restart, choose Restore latest session in the tray menu, or press Restore next to a session in the manager. Your documents reopen with the cursor where you left it.

Even if you never save by hand, autosave keeps a recent copy of what you had open every 10 minutes.

Set up and first run

Word Session needs no installation and no administrator rights. Everything it sets up is for your Windows account only.

  1. Unzip WordSession-<version>-win64.zip into a folder of your own, for example %LOCALAPPDATA%\Programs\WordSession. Keep the folder where it is afterwards: the Start menu shortcut and start at login point into it.
  2. Double-click word-session.exe in that folder.
  3. In the manager that opens, go to Settings and press Create Start menu shortcut.
  4. Optionally, tick Start at login in the tray menu so Word Session starts every time you sign in.

First run

When Word Session starts, its icon appears in the notification area (click the ^ arrow next to the clock if it is hidden; you can drag it out to keep it visible) and the manager opens in your default browser.

Only one Word Session runs per Windows user. Starting it a second time just opens the manager of the one already running.

The manager

The manager is a page in your web browser, served by Word Session itself on your own computer. It is not a website: nothing leaves your computer.

Opening the manager

Open it with Open manager… in the tray menu, by clicking the tray icon, by starting Word Session from the Start menu, or with word-session-cli open. Each of these opens the browser with a one-time sign-in link, so that no other program or website can use the manager.

If a tab says Not signed in (for example after Word Session was restarted, or when you open the address from a bookmark), open the manager from the tray again. Tabs you already have open stay signed in while Word Session runs. This help page needs no sign-in.

The top bar

  • Sessions, Open now, Settings, Diagnostics switch between the pages described below. Help opens this guide in a new tab.
  • The Word indicator on the right shows whether Word is running (green dot, with its version) or not (red dot). It is checked every 10 seconds and never starts Word.
  • A red bar Word Session is not running means the page lost contact with Word Session, for example because you chose Quit. Start Word Session again; the page reconnects by itself.

Every button has a tooltip: rest the mouse pointer on it to see what it does. The small ? links open the matching part of this guide in a new tab.

Sessions page

The start page lists every saved session, newest first.

Save current session

Type a name in Session name (optional) and press Save current session. The documents open in Word right now are saved as a new manual session. Without a name the session is called Session plus the date and time. Messages at the bottom of the page confirm the save and warn about documents that cannot be restored:

  • a document that was never saved (Document1) has no file to reopen; it is listed in the session but skipped on restore;
  • a document with unsaved changes will be reopened from its last saved version. Save it in Word to keep the changes.

If Word has no documents open, nothing is saved. If Word is not running, you get the message Word is not running.

Search

Type in Search to show only the sessions whose name, id, or any document path contains the text (upper and lower case do not matter). For example, thesis finds every session that had a file from your thesis folder open.

Filters

The filter buttons narrow the list further. Click one to switch it on (highlighted), click again to switch it off.

  • manual, auto, imported: only sessions of that kind. Only one kind can be on at a time.
  • pinned: only pinned sessions. Combines with a kind.

One session

Click a session in the list to see and change it. Sessions at the top left takes you back to the list.

Rename

Press Rename, type the new name and press Save name (or Enter). Cancel (or Esc) keeps the old name. Renaming does not change the session's id.

Pin

Same as Pin in the list: protects the session from automatic clean-up.

Details

Id is the session's permanent identifier (and its file name), Created the time it was saved, Host the computer it was saved on and Word version the version of Word that was running.

Notes

Free text for yourself, for example what you were working on. Type and press Save notes. word-session-cli show prints them, and word-session-cli notes sets them from the command line.

Restore selected

Reopens only the ticked documents. Untick what you do not need first. See How restoring works.

Remove selected from session

Removes the ticked documents from this session, after you confirm. The files themselves are not touched. Use it to tidy a session that collected documents you no longer want, or to drop missing files.

Delete session

Deletes the whole session after you confirm. The session file is moved to the trash folder inside the sessions folder, so you can get it back by moving the file out again (see Where your files live). The documents themselves are not touched.

Restore progress and results

During a restore a progress bar counts the documents. When it ends, the panel says Restore finished or Restore finished with problems and lists every document with its result:

StatusMeaning
openedThe document was opened and the cursor placed.
already_openIt was already open in Word; it was not opened again, but the cursor was put back.
skippedIt was never saved, or this was a dry run.
missingThe file is no longer there.
lockedSomeone else, or another program, has the file open.
failedWord could not open it; the message says why (for example a dialog was open in Word).

A message such as position not restored next to an opened document means the document opened but the cursor could not be placed.

Changes from another tab

If the session was changed elsewhere (another tab, the tray, the command line) while you were editing it, your change is not applied; the page shows This session was changed in another tab and loads the latest version. Make your change again.

Open now page

Shows whether Word is running and lists the documents open in it right now, with their location and cursor position. This is exactly what a save would capture when nothing is ticked.

Tick the boxes of some documents to work with just those. Save selected as session… asks for an optional name and saves the ticked documents as a new manual session, like Save current session. The ticks stay after saving, so you can then press Close now to close the same documents in Word. Close now asks for confirmation and never discards work: documents with unsaved changes stay open and are reported.

Settings page

Change the settings and press Save settings. Changes apply at once; there is no need to restart.

Autosave

Autosave enabled
Saves the open documents in the background. Same as the tray's Autosave item. Default: on.
Autosave interval (minutes)
How often to check Word, from 1 to 1440. Default: 10.
Automatic sessions to keep
How many automatic sessions are kept; older ones are moved to the trash. From 0 to 10000. Pinned, manual and imported sessions are never removed. Default: 20.
Autosave only when something changed
Skip the autosave when the same documents are open, in the same order, with the same cursor positions and the same document in front, as in the newest automatic session. Default: on.

Restore

Start Word when restoring
Starts Word if it is not running when you restore. When off, restoring with Word closed fails with Word is not running. Default: on.
Restore cursor positions
Puts the cursor back where it was. When off, documents open at the top. Default: on.
Open timeout (seconds)
How long to wait for Word to open one document before reporting it as failed, from 1 to 3600. Raise it for very large documents or slow network drives. Default: 60.

General

Sessions folder
Where session files are stored. Leave it empty for the default (%APPDATA%\word-session\sessions). Point it at a folder you back up or sync if you like. Existing sessions are not moved; move the files yourself.
Start at login
Start Word Session when you sign in to Windows. Same as the tray's Start at login item.

Start menu

Create Start menu shortcut adds a Word Session entry to your own Start menu (%APPDATA%\Microsoft\Windows\Start Menu\Programs). Other users of the computer do not see it, and no administrator rights are needed. The entry starts Word Session and opens the manager; if Word Session is already running, it just opens the manager.

The shortcut points at the folder Word Session runs from now. If you move that folder, start word-session.exe from the new place and press Recreate Start menu shortcut. Remove Start menu shortcut takes the entry out again; nothing else is changed. From the command line: word-session-cli shortcut and word-session-cli shortcut --remove.

How restoring works

  • Nothing is closed. Documents you already have open stay open; documents of the session that are already open are not opened a second time (their cursor is still put back).
  • Every document is tried. A missing, locked or failing document does not stop the others. You always get a per-document report.
  • The front document ends up in front. The document that was active when you saved is opened last.
  • The cursor goes back. Word Session remembers the exact character position and also the page and line. If the document has changed so much that the position no longer exists, page and line are used instead.
  • Word is started if needed, unless you switched off Start Word when restoring.
  • One restore at a time. Starting a second restore while one is running is refused; wait for the first to finish. Autosave pauses during a restore.
  • Saved versions are opened. A document that had unsaved changes when the session was saved opens as it was last saved in Word. Never-saved documents are skipped.
  • Read-only stays read-only. A document that was open read-only is reopened read-only.

Autosave and clean-up

While Word Session runs, it looks at Word every autosave interval (10 minutes by default) and saves an automatic session named Autosave plus the date and time. It skips the save when:

  • Word is not running (autosave never starts Word);
  • Word has no documents open;
  • nothing changed since the last automatic session (unless you switched off Autosave only when something changed);
  • a restore is running.

After each autosave, only the newest 20 automatic sessions (the number to keep) are kept; older ones are moved to the trash folder. Manual and pinned sessions are never removed automatically.

If an autosave fails, for example because Word shows a dialog, the tray icon shows a warning and a notification says why. The next successful autosave clears it.

Switch autosave on or off with the tray's Autosave item or on the Settings page.

Pinned sessions

Pinning protects a session from automatic clean-up and lists it first in the tray's Recent sessions. Pin an automatic session to keep it for good. Pin with the Pin button or word-session-cli pin <session>; unpin the same way or with word-session-cli unpin <session>.

Command line

Everything the manager does is also available as a command, for scripts, shortcuts and keyboard users. Open a terminal in the folder you unzipped Word Session into (the one with word-session.exe), or add that folder to your PATH.

Naming a session

Wherever a command takes SESSION, you can write, checked in this order:

  1. latest, latest-manual or latest-auto;
  2. -1, -2, … for the newest, second newest, …;
  3. the path of a session .json file, anywhere;
  4. the exact id;
  5. the exact name (upper and lower case do not matter);
  6. the first four or more characters of the id, if only one session matches.

If a name or id start matches several sessions, the command lists them and does nothing; use more of the id.

Exit codes

0Success.
1Error.
2Wrong command or options.
3Word is not running or not installed.
4Restore finished, but some documents failed.
5No session matches, or several do.
6Word is not responding.

Examples

word-session-cli save --name "Thesis chapter 3"
word-session-cli list --kind manual
word-session-cli restore                       # the latest session
word-session-cli restore thesis                # by name
word-session-cli restore -2 --only "*.docx"    # second newest, .docx only
word-session-cli restore --dry-run             # what would open?
word-session-cli pin 20261031T1430
word-session-cli diff -2 -1                    # what changed since last time?

Each session is one small text file named after its id, which you can copy, back up or sync. To undo a delete, move the file from trash back into the sessions folder.

The settings file is plain text and can be edited while Word Session is stopped. It holds the same settings as the Settings page:

# %APPDATA%\word-session\config.toml
sessions_dir = "D:\\Backup\\word-sessions"   # optional

[autosave]
enabled = true
interval_minutes = 10
keep = 20
only_on_change = true

[restore]
start_word = true
restore_position = true
open_timeout_s = 60

[ui]
start_at_login = false

Privacy and security

  • The manager is served only to your own computer (address 127.0.0.1); other computers on the network cannot reach it.
  • Opening the manager requires a one-time sign-in link that only Word Session can create, so other programs and websites in your browser cannot use it.
  • Word Session makes no internet connections. Sessions store file paths and cursor positions, never document contents.

Troubleshooting

Start with the Diagnostics page or word-session-cli doctor: lines marked warn or fail say what to fix.

"Word is not responding"

Word is busy or showing a dialog, for example Save changes?, a sign-in prompt or the document recovery pane. Switch to Word, close the dialog, and try again. For very large documents, raise the Open timeout.

"Word is not running" although Word is open

  • Word makes itself available to other programs only after it has had focus once or has a document open. Click into a Word window or open a document, then try again.
  • If either Word or Word Session was started as administrator, they cannot see each other. Start both normally. The elevated check reports this.

Documents are reported as missing

The file was moved, renamed or deleted, or the drive or network share is not connected. Reconnect the drive and restore again. To clean up the session, select the missing documents and use Remove selected from session.

Documents are reported as locked

Someone else, or another program, has the file open for editing. Close it there, or open it read-only from Word.

Files on OneDrive or SharePoint

Documents opened from the web are saved by their address and reopened from it; you need to be signed in to Office. Documents in a synced OneDrive folder behave as local files, but an online-only file may take a moment to download while it is restored.

Some documents are not in the session

A document that has never been saved has no file, so it cannot be reopened; it is listed as unsaved and skipped. Save it in Word first, then save the session again.

The manager says "Not signed in"

Open it again with Open manager… in the tray menu or word-session-cli open. Bookmarks to the manager do not work after Word Session restarts, because it chooses a new address each time.

The tray icon is missing

Click the ^ arrow next to the clock; Windows may hide new icons there. If Word Session is not running, start it from your Start menu shortcut or with word-session.exe. If starting it does nothing, run word-session-cli open in a terminal and look at the log (path in Where your files live).

Autosave does not save

Check that Autosave is ticked in the tray menu and that Word is running with documents open. With Autosave only when something changed on, no new session appears while nothing changed; this is intended.

Reporting a problem

Open the Diagnostics page, press Copy report and paste the result into your message.

Remove Word Session

  1. Untick Start at login in the tray menu.
  2. Press Remove Start menu shortcut on the Settings page.
  3. Choose Quit in the tray menu.
  4. Delete the folder you unzipped Word Session into.

Your sessions and settings are kept. Delete %APPDATA%\word-session and %LOCALAPPDATA%\word-session as well if you want them gone.
