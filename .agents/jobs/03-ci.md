# Job 03 — CI workflow

Depends on: 02
Plan reference: §4 (CI)

## Goal

Run formatting, lint, type check and tests on every push and pull request on
a Windows runner, so regressions are caught without a local Word install.

## Files

- `.github/workflows/ci.yml`

## Do

1. Workflow `ci`, triggers: `push` to `main`, `pull_request`.
2. One job `checks` on `windows-latest`:
   - `actions/checkout@v4`
   - `astral-sh/setup-uv@v5` with `enable-cache: true`
   - `uv python install` (reads `.python-version`)
   - `uv sync --frozen`
   - `uv run ruff format --check .`
   - `uv run ruff check .`
   - `uv run pyright`
   - `uv run pytest --cov=word_session --cov-report=term-missing`
3. A second job `checks-linux` on `ubuntu-latest` running only
   `uv sync --frozen` and `uv run pytest -m "not word and not ui"`; it
   proves the core imports without pywin32 (README rule 4). Allow it to
   install without pywin32 (the marker in `pyproject.toml` handles that).
4. Packaging steps are added by job 20; leave a comment
   `# packaging: added in job 20` at the end of the Windows job.

## Do not

- No secrets, no deployment, no caching beyond setup-uv's.

## Acceptance

- YAML is valid: `uv run python -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml'))"`
  (use `uv run --with pyyaml python ...`).
- The commands the workflow runs all pass locally.
- There is no GitHub remote yet; the coordinator notes in `STATUS.md` that
  the workflow has not run remotely.

## Report

Standard report.
